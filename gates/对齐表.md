## 3. 一键门禁

```bash
/root/deslop/run_gates.sh <file> [--erotica] [--zhuque] [--quiet]
```

- 语言自动路由（汉字占比 >8% 走中文闸，否则英文闸）
- 中文闸顺序：density_check → check_prose → story-deslop(blocking) → [情色 check_erotica] → [朱雀]
- 退出码：0 全绿 / 1 有 blocking / 2 用法错误
- 片段豁免：<400 汉字且唯一 ✗ 是「对话引号」时不计 FAIL（该条是章节级判据）

朱雀需先配 Key（三选一，见 `zhuque_check.py` 报错提示），免费 50 万 token/月，约 1.7 token/字。

## 4. 还缺什么（按性价比排序）

1. **句长方差**（#26）：每段句长标准差低于阈值即报 —— 20 行代码，可脚本化
2. **感知动词开句**（`我能清晰地/我看到/我听到`）：现有规则只在情色 skill 的 QUOTA 层，应升为通用项
3. **开篇起手式词表**（#29）：夜色如墨/月光如水/空气仿佛凝固（后者已在零频套语）
4. **台词长度分布**（#20/22/23）：需要识别引号内文本，用长度直方图判"全场惜字如金"
5. **环境段占比**（#30–33）：段落里纯景物描写判据

前 3 条可以脚本化；后 2 条要给 LLM 判，脚本最多做候选定位。
